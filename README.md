## ✦ About

**SKiL MATRiX** is a modern academic ecosystem designed around the everyday needs of students.

From discovering study resources to preparing for examinations, practicing coding, tracking academic performance and staying productive — SKiL MATRiX brings essential student experiences together in one place.

> **One platform. One academic journey.**
